# To-Day
A to-do list that resets at midnight.

[Github Pages Deployment](https://tammyhi.github.io/To-Day/)

### [❗ Motivation](#-motivation) | [🥩 Features](#-features) | [🚃 To-Do](#-to-do) | [📝 Self-Notes](#-self-notes) 

## ❗ Motivation
Problem: I would always overplan my tasks to do, whether on paper or digitally. I would plan out tasks to do for the next month or week, only to get overwhelmed and not follow the plan.

Solution: Create a to do list that resets in 24 hours so I can't overplan and will only focus on what I can get done during a day.

## 🥩 Features
- Time widget that updates in real time
- Add tasks
- Edit tasks
- Remove tasks
- Localstorage
- Two lists for completed and incomplete tasks
